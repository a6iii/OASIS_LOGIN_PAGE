# OASIS Level 2 Task 4 - Login Authentication System

This is a simple Login Authentication System developed for the OASIS Internship (Level 2, Task 4). 
The project allows users to register with a unique username and password, and then login to access a protected page.
The system uses Python and file handling to store and validate user credentials in a local file (users.txt).

## Features
- User Registration (New users can register with username and password)
- User Login (Registered users can login using their credentials)
- Protected Page (Accessible only after successful login)
- Simple and beginner-friendly Python implementation

## Technologies Used
- Python 3.14
- File Handling (users.txt)
- VS Code

## How to Run
1. Clone the repository:
git clone https://github.com//OASIS_Login_Page.git

2. Open the project folder in VS Code  
3. Run the program in terminal:
python login.py
  

4. Follow the on-screen instructions to register and login
