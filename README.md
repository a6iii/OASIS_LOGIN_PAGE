# OASIS_LOGIN_PAGE - OASIS Level 2 Task 4

This is a simple Login Authentication System developed for the OASIS Internship (Level 2, Task 4). 
The project allows users to register with a unique username and password, and then login to access a protected page.
The system uses Python and file handling to store and validate user credentials in a local file (users.txt).

## Features
- User Registration
- User Login
- Protected Page
- Simple Python implementation

## Technologies Used
- Python 3.14
- File Handling (users.txt)
- VS Code

## How to Run
1. Open the project folder in VS Code  
2. Run the program in terminal:
python login.py

3. Follow the on-screen instructions to register and login
